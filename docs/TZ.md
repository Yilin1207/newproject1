# ТЗ: браузерная игра «Наш район»

## Идея

**Уточнение текущего этапа:** только фронтенд на Next.js и Tailwind CSS,
минимум три работающие страницы, без 3D и серверных задач.
Данные демо сохраняются в браузере. Идея полной версии ниже остаётся ориентиром.

2–4 игрока вместе готовят район к грозе: собирают припасы, переносят предметы и распределяют электричество между зданиями. У каждого есть личная цель. Решения влияют на концовку.

## Распределение работы

- **Акжол — интерфейс:** главная, лобби, выбор персонажа, адаптивная вёрстка и визуальные компоненты.
- **Ерасыл — логика фронтенда:** профиль, локальное состояние, подготовка района, результаты, интеграция и проверки. Бэкенд отложен.

## Стек

Текущий MVP: Next.js, React, TypeScript, Tailwind CSS, localStorage.

Возможный стек полной игры: Three.js, Rapier, Node.js, Express, Socket.IO, PostgreSQL.

## Готовый результат

Игроки с разных компьютеров заходят в одну комнату, видят действия друг друга, выполняют задания и получают общий итог. Результат сохраняется в профиле.
