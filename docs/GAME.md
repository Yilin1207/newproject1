# Игровая сцена «Перед грозой»

Этот проход добавляет локальную играбельную 3D-сцену к существующему фронтенду. Главная, профиль, навигация, выбор персонажа и комната сохраняются. Содержание сценария взято из README; видео используется только как визуальный ориентир.

## Запуск

Требуются Node.js 20.9 или новее и npm, как указано в `package.json`.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000, перейдите в игровую комнату, создайте комнату или войдите по `DEMO26`. Выберите героя, нажмите «Я готов», затем существующую кнопку «Начать подготовку». Во время инициализации движка показывается экран загрузки. Нужен браузер с поддержкой WebGL 2.

## Управление

| Действие | Управление |
|---|---|
| Ходьба | WASD или стрелки |
| Бег | Shift + направление |
| Прыжок | Пробел |
| Вращение камеры от третьего лица | Перетаскивание мышью по сцене |
| Приближение камеры | Колесо мыши |
| Поднять, доставить или установить предмет рядом | E |
| Бросить переносимый предмет | Q |
| Пауза | Escape или кнопка паузы |

За один раз можно нести один предмет; с грузом герой движется медленнее. Подсказка E появляется в зоне взаимодействия. Брошенный предмет можно снова подобрать.

## Сценарий

До грозы есть **10 минут**. В районе пять основных мест: общий дом, магазин, площадка с генератором, центральная площадь и мост.

- Найдите еду, воду и тёплые одеяла и по одному доставьте к входу в общий дом.
- Принесите доски к входу на мост и укрепите его.
- Заберите единственный аккумулятор у генератора и установите его у общего дома **или** магазина. Изменить уже принятое решение в этой партии нельзя. Свет в доме помогает соседям, электричество в магазине спасает продукты.

У каждого выбранного героя есть личная цель: Мира собирает все припасы, Саша укрепляет мост, Рен спасает продукты магазина, Тим оставляет свет в общем доме. Цель Рена намеренно создаёт выбор между личным интересом и общим результатом.

Можно дождаться таймера или досрочно встретить грозу кнопкой в игре. Во время грозы подготовка завершается: новые предметы уже не засчитываются. Через 18 секунд отображаются общий результат и выполнение личной цели. Освещение зданий и состояние моста отражают принятые решения.

Лучший общий результат требует всех трёх припасов, укреплённого моста и света в общем доме. Другие сочетания дают другие итоги; выбор магазина отдельно учитывается в концовке.

Из паузы можно продолжить или вернуться в исходное лобби. Незавершённая партия при выходе сбрасывается. После результата можно начать новую партию без перезагрузки страницы. Завершённый результат сохраняется в существующей локальной истории профиля.

## Проверки

```sh
npm run test:game
npm run typecheck
npm run build
```

Тесты модели проверяют полный успешный цикл, альтернативу с магазином, личные цели, ограничения взаимодействия и переноски, невозможность повторно засчитать предмет, восстановление после броска, таймер и повторный старт. Они не заменяют ручную проверку 3D-управления, кнопок, WebGL и ошибок браузера.

## Границы реализации

Это локальный игровой режим в браузере. Демонстрационные соседи в лобби не являются сетевыми игроками. Синхронизация между компьютерами, авторизация, серверная проверка действий и PostgreSQL в этом фронтенд-проходе не реализованы. Полная сетевая архитектура из README остаётся отдельным этапом.

Профиль и история используют существующий `localStorage`; очистка данных сайта удаляет их. Текущая 3D-партия не сохраняется для продолжения после обновления страницы. Для игры не нужны ключи, база данных или отдельный игровой сервер.
