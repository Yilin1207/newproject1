# Демо «Наш район»

## Запуск

Node.js 20.9+ и npm. Рекомендуется актуальная LTS-версия Node.js.

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000. Сервер игры, база данных, ключи и переменные окружения не нужны.
Для проверки production: `npm run build`, затем `npm start`.

## Три страницы

| Адрес | Что работает |
|---|---|
| `/` | Главная, описание сценария, переход в лобби, правила в диалоге |
| `/lobby` | Создание локальной комнаты, вход по DEMO26, выбор героя, готовность, подготовка, варианты результатов, повтор и выход |
| `/profile` | Изменение имени и героя, настройки подсказок и переходов, статистика, история, очистка с подтверждением |

## Показ за 3–5 минут

1. На главной показать описание проекта и открыть правила. Закрыть диалог кнопкой или Escape.
2. В профиле изменить имя, выбрать персонажа, сохранить. Имя появится в шапке.
3. Открыть игровую комнату. Ввести неверный код из шести символов — появляется понятная ошибка.
4. Ввести **DEMO26** или нажать «Создать комнату».
5. Выбрать персонажа. До подтверждения готовности кнопка начала недоступна.
6. Нажать «Я готов», затем «Начать подготовку».
7. Собрать припасы, укрепить мост, направить аккумулятор в общий дом.
8. Нажать «Встретить грозу»: район готов, результат добавлен в профиль.
9. Повторить с электричеством в магазине или без подготовки — итог отличается.
10. Обновить страницу: имя, настройки, состояние комнаты и история сохраняются.

## Границы демо

- Это фронтенд-прототип, а не сетевая игра. Соседи в лобби помечены как демо.
- Код DEMO26 демонстрирует форму подключения. Произвольные коды и приглашения других устройств не работают без будущего сервера.
- Нет регистрации, паролей, серверной авторизации, 3D, движения персонажей или реального времени.
- Данные хранятся в localStorage под ключом `nash-rayon.frontend.v1`. История ограничена 30 результатами.
- Удаление данных сайта удаляет профиль. В приватном режиме срок хранения зависит от браузера.
- Если браузер запрещает хранилище, состояние работает в памяти вкладки; формы сообщают об ошибке сохранения.
- Иллюстрация и аватары — локальные SVG-компоненты, внешние изображения и шрифты не загружаются.

## План разделения работы на двух участников

Это распределение ответственности и дальнейшей проверки, а не утверждение о фактическом авторстве уже созданных изменений.

| Участник | Сопоставимый блок задач | Что проверить и доработать самостоятельно |
|---|---|---|
| Акжол | Главная, лобби, персонажи, общий макет, адаптивная вёрстка | Мобильные состояния, тексты, доступность навигации и диалога, оформление карточек |
| Ерасыл | Профиль, настройки, локальное состояние, сценарий, результаты и интеграция | Проверки форм, сохранение и восстановление, история, ошибки хранилища, сборка |

Текущий Git-аккаунт `Yilin1207` принадлежит Ерасылу.
Подготовленные с помощью ассистента изменения сгруппированы в два блока для проверки участниками:

1. Ерасыл: настройка Next.js и Tailwind, общий макет и UI-компоненты, профиль, настройки и локальное состояние.
2. Акжол: главная, лобби со сценарием подготовки, иллюстрация района и документация демо.

Для указания второго автора в Git нужны имя и email, не пароль.
Такое распределение подготовленного кода само по себе не подтверждает личный вклад участников.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
```

Ручной минимум: три маршрута, ошибочный/верный код, блокировка старта без готовности,
успешный/неполный итог, сохранение профиля и истории после обновления, отмена выхода,
Escape в диалоге, экран телефона и клавиатурная навигация.
