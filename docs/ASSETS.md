# Ресурсы игровой сцены

В этой реализации не загружаются сторонние модели, текстуры, изображения,
шрифты или аудиозаписи. Сцена и её ресурсы создаются локально кодом проекта.
Сеть не требуется для загрузки художественных ресурсов после получения
приложения и его JavaScript-файлов.

## Геометрия и анимация

- `src/game/World.tsx` — созданное для проекта стилизованное окружение:
  здания, черепичные крыши, окна и ставни, вывески, генератор, мост, канал,
  фонтан, скамейки, фонари, деревья, трава, цветы, листья и дальний фон.
- `src/game/Character.tsx` — созданная для проекта модель персонажа и
  процедурная анимация ходьбы, бега, рук, корпуса и шарфа.
- `src/game/ItemVisual.tsx` — созданные для проекта предметы: ящик продуктов,
  питьевая вода, одеяла, доски и аккумулятор.
- `src/game/Engine.tsx` — эффекты дождя, света, погоды и отображение игровых
  объектов; `src/game/WorldLabel.tsx` — текстуры и отображение игровых меток.

Модели построены средствами Three.js. Статическая геометрия объединяется
по материалам, а трава, цветы и листья используют экземпляры геометрии.
Отдельных загруженных файлов моделей и скелетных анимаций нет.

## Текстуры и эффекты

Каменное мощение, травяной покров, вывески и игровые метки рисуются через
Canvas API в коде приложения. Вода использует локальный GLSL-шейдер.
Системные шрифты используются через стандартный механизм подстановки
шрифтов браузера; файлы шрифтов в проект не копируются.

Существующие SVG-компоненты исходного фронтенда сохранены. Новые внешние
графические ресурсы для них не добавлялись.

## Звук

`src/game/audio.ts` синтезирует звуковой фон и короткий сигнал успешного
действия через Web Audio API: используются генерируемый шум, фильтры,
осцилляторы и огибающие громкости. Семплы, музыка и аудиозаписи третьих
лиц не использованы.

## Видео-ориентир

Предоставленное пользователем видео использовано только как визуальный
ориентир для палитры, освещения, атмосферы и движения. Его кадры, звук,
персонажи, модели и графика не включены в приложение. Содержание сценария
определяется README проекта.

## Библиотеки и лицензии

Код библиотек, включая Three.js, React Three Fiber, Drei, Rapier и средства
постобработки, регулируется лицензиями соответствующих npm-пакетов.
Точные установленные версии зафиксированы в `package-lock.json`, а тексты
лицензий поставляются в пакетах зависимостей. Эта заметка описывает
происхождение ресурсов и не заменяет условия этих лицензий, а также
не задаёт отдельную лицензию для самого репозитория.
