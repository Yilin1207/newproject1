# Наш район

Кооперативная браузерная 3D-игра для 2–4 игроков.
Учебный проект по предмету «Фронтенд и бэкенд разработка».

## Идея

Игроки вместе готовят район к грозе: собирают припасы,
переносят предметы и решают, какие здания обеспечить
электричеством. У каждого есть личная цель, а совместные
решения влияют на концовку.

## Планируемые возможности

- Регистрация и вход.
- Создание комнаты и подключение по коду.
- Управление персонажем от третьего лица.
- Совместная игра с синхронизацией действий.
- Сбор припасов и перенос предметов.
- Общие задания и личные цели.
- Сохранение результатов в профиле.

## Технологии

- Фронтенд: Next.js, React, TypeScript.
- 3D и физика: Three.js, Rapier.
- Бэкенд: Node.js, Express, Socket.IO.
- База данных: PostgreSQL.
